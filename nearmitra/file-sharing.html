FILES BELONG IN THE CONVERSATION

Send it.

Share text, files and folders from a selected device conversation. Windows displays incoming progress, bytes, transfer speed and remaining time where available.

  • Direct local routes preferred when available
  • File and folder selection on supported builds
  • Replies, reactions, copy and forwarding in chat
  • Received-file access from your desktop workflow

YOUR FIRST TRANSFER

Three small steps.

  1. 01

    Connect

    Open NearMitra on both devices and establish a reachable LAN or supported P2P connection.

  2. 02

    Select & send

    Open the device conversation. Choose Send File or Send Folder and select the content you want to transfer.

  3. 03

    Follow the progress

    Keep both devices connected and watch the transfer. Open the received file or folder after completion.

LOCAL CONNECTIONS, PRACTICAL EXPECTATIONS

Let your network do the work.

Transfer speed depends on Wi-Fi quality, storage, device hardware and network congestion. UI speed labels are not a measured performance guarantee.

Understand connection modes

Local TCP file and chat transport is not universally end-to-end encrypted. Use trusted peers and networks, and review what you send.
