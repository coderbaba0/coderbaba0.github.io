HELP & FAQ

Before you connect.

Does NearMitra need the internet?+

Nearby chat and file transfers use a working local LAN or supported Wi-Fi Direct/P2P connection. WAN requires internet and your own Firebase setup. Cloud AI providers also need internet; a local Ollama host depends on the model and host configuration.

Can my Android phone connect to my Windows PC?+

Yes. Run NearMitra on both devices, join the same local network or establish a supported P2P link, then discover and select the other device. Approve access requests on the receiving device.

Where can I download the Android APK or Windows installer?+

Check the project’s GitHub Releases for published assets. Local build filenames in the repository documentation are not public download links. If an asset is not published, follow the build instructions in the source repository.

What happens when I swipe the Android app away?+

Swipe-away delivery remains a known issue. The service notification can stay visible while the Flutter networking runtime is unavailable, and messages may appear after reopening. Use Home or the app’s Back-to-background behavior with Run in Background enabled; this is not a guarantee against Android or manufacturer restrictions.

Does every connection have end-to-end encryption?+

Do not assume that. Local TCP chat, file and AI paths are not universally end-to-end encrypted. WebRTC uses its own media/data-channel transport security. Only connect devices and networks you trust.

Can I share my desktop’s local AI with my phone?+

Yes, for supported configured engines. On Windows, configure the engine in My AI, select the phone and grant Share my AI access. The phone can then use that device’s Nearby AI. The owner can revoke access.

Does the public source use the author’s Firebase?+

No shared maintainer backend is configured in the public source. Contributors must provide their own local Firebase project and RTDB URL for WAN. Both endpoints must use the same backend. Configuration files are Git-ignored.

Is NearMitra open source?+

Yes. NearMitra source is licensed under GPL-3.0-only. Contributions, source changes and redistribution must follow that license. Read LICENSE and CONTRIBUTING.md in the project repository.

Can Windows audio become my phone’s speaker stream?+

Windows Voice → Broadcast PC Audio to Phone supports direct Nearby/P2P sessions with Android Wi-Fi Audio. The phone must approve the request. All-PC capture needs an active playback output; NearMitra does not install a virtual audio driver.

Why can’t I discover another device?+

Check both apps are running, both devices share a reachable network, permissions are granted and Windows private-network firewall access is allowed. Guest Wi-Fi isolation, VPNs or separate subnets can block local discovery. Try the app’s manual IP or QR pairing options where available.
