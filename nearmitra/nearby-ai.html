NEARBY AI

One engine.
More places to ask.

My AI configures the current device’s own engine. Nearby AI connects a device conversation to that selected peer’s shared engine. They are separate controls with separate permissions.

  • Configure supported engines on the host
  • Approve access for a specific device
  • Stream actual Ollama response chunks
  • Stop a request or revoke sharing access

FROM OLLAMA TO YOUR PHONE

Set up once. Share deliberately.

  1. 01

    Configure the host

    Install/configure Ollama separately on Windows and select an installed model in NearMitra’s My AI settings.

  2. 02

    Allow the phone

    Select the phone’s conversation on Windows. Choose Share my AI with this device → Allow.

  3. 03

    Ask from Android

    Open that Windows device’s Nearby AI on the phone and send a prompt. Keep the direct connection and host engine available.

Nearby AI requires a direct Nearby/P2P peer; WAN-only AI sharing is not added. Prompts go to the selected host engine. Cloud engines follow their provider’s network and data policies, and generation quality depends on the model.
