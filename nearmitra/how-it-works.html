NearMitra/How it works

A CONNECTION THAT STARTS CLOSE.

Nearby first.
Further when needed.

NearMitra starts with reachable devices around you. Internet/WAN is a separate, optional path with your own discovery and signaling backend.

THREE WAYS TO CONNECT

Choose your reach.

01 / NEARBY LAN

Share a network.

Join a reachable local Wi-Fi/LAN network. Discover your other device and use the direct route for local chat and transfers.

02 / DIRECT P2P

Make a direct link.

Use supported Wi-Fi Direct/P2P capability. Availability and connection setup depend on the platform and network adapter.

03 / INTERNET WAN

Reach beyond local.

Configure your own Firebase RTDB for remote discovery, presence and signaling. Supported sessions use a negotiated WebRTC connection.

START LOCAL

A good first test.

  1. 01

    Keep both devices open

    Use current compatible builds on Android and Windows. Avoid duplicate older Windows tray instances.

  2. 02

    Connect & approve

    Use the same reachable LAN. Select the peer and approve the feature request on the receiving device.

  3. 03

    Try a message and file

    Confirm direct chat and a small transfer before testing audio, camera or AI sharing.

FOR DEVELOPERS

Bring your own WAN backend.

The public source includes placeholders and setup instructions. Both endpoints must use the same database. Firebase is used for discovery/signaling; it is not a public shared service provided with the project.

Read the Firebase setup guide

Current clients do not implement a Firebase Auth token flow. Hosted deployment requires compatible authentication and database rules; use the documented isolated emulator for development. Pairing is not database authorization.
