YOUR FIRST CONNECTION

From install to hello.

  1. 01

    Open both apps

    Install or build NearMitra for Android and Windows. Keep both apps open for your first test.

  2. 02

    Join a reachable network

    Connect both devices to the same LAN, or set up a supported P2P connection. Grant the requested permissions for the feature you use.

  3. 03

    Choose a device

    Select the PC, send a short message and try a small file. Approve any sharing request on the receiving device.

Background behavior: Run in Background keeps the intended minimized workflow available, but swiping the app out of Recent apps still has a known message/notification delivery issue. See the FAQ before depending on background delivery.
