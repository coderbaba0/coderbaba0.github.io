    Read the guide

    Show the result

    Make a focused change, run the relevant checks and describe what changed and how you verified it.

THE STACK

Two platforms.
A shared purpose.

Android combines Flutter with native Kotlin integration. Windows uses a native Go application with a web-based interface. Direct local links and supported WebRTC sessions connect the experience.

  • Flutter + Kotlin on Android
  • Go desktop application on Windows
  • Optional owner-configured Firebase RTDB for WAN
  • Supported local AI hosting with Ollama
