GOOD QUESTIONS

A few things to know.

Does NearMitra need the internet?+

Nearby chat and file transfers use a working local LAN or supported Wi-Fi Direct/P2P connection. WAN requires internet and your own Firebase setup. Cloud AI providers also need internet; a local Ollama host depends on the model and host configuration.

Can my Android phone connect to my Windows PC?+

Yes. Run NearMitra on both devices, join the same local network or establish a supported P2P link, then discover and select the other device. Approve access requests on the receiving device.

Where can I download the Android APK or Windows installer?+

Check the project’s GitHub Releases for published assets. Local build filenames in the repository documentation are not public download links. If an asset is not published, follow the build instructions in the source repository.
