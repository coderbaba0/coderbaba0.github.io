NearMitra/Agents & MCP roadmap

A POSSIBLE NEXT CHAPTER

Connected devices.
Considered actions.

Today: chat with a shared engine. A future direction: ask an agent to use clearly scoped, owner-approved tools across your devices. This page describes possibilities, not a release commitment.

START WITH WHAT EXISTS

A real foundation.
A clear boundary.

The current app connects devices, transfers files and provides permission-based AI engine sharing. It does not ship a general agent runtime or MCP server.

AVAILABLE IN CURRENT SOURCE

Connect & converse

Nearby chat and transfers. Supported camera/audio workflows. Configure an AI host, grant a device access and exchange prompts and responses.

PROPOSED DIRECTION

Review & delegate

A possible agent layer could translate a request into a visible action plan, then request approval for the target device and selected resources.

PROPOSED DIRECTION

Integrate approved tools

An MCP integration could make a narrow set of NearMitra capabilities available to compatible AI clients, with permissions enforced by the owner.

WHY MCP?

A common interface.
Explicit permission.

Model Context Protocol provides a standard way for AI applications to connect to tools and data sources. It does not, by itself, make a tool safe or give an agent permission to act.

Read the official MCP introductionDiscuss an integration proposal

WHAT A RESPONSIBLE DESIGN WOULD NEED

Small scopes.
Visible decisions.

These are proposed design requirements for a future contribution, not guarantees of the current implementation.

  • An explicit list of tools and target devices; no implicit access to everything.
  • Owner approval for sensitive actions, with an understandable preview before execution.
  • Authentication, scoped authorization and revocation enforced at the tool boundary.
  • A visible action history, cancellations and clear failure reporting.
  • Tests for denied, revoked and disconnected sessions before release.

No agent or MCP release date is announced here. Ideas need a design review, implementation, security work and cross-device testing. The source repository is the authority on what has shipped.
